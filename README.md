# DIU Cover Page Generator — Free PDF Tool for DIU Students

> **🌐 Live Website → [diu-covergen.vercel.app](https://diu-covergen.vercel.app/)**
>
> *This is the source code repository. To use the tool, visit the link above.*

---

**DIU CoverGen** is a free online cover page generator for **Daffodil International University (DIU)** students. Generate professional cover pages for Theory Assignments, Lab Reports, Lab Finals, and more — and download as PDF instantly. No Microsoft Word needed.

## 🔗 Use the Tool

👉 **[https://diu-covergen.vercel.app/](https://diu-covergen.vercel.app/)**

Supports:
- **Theory Assignment Report** cover page (5 marks rubric)
- **Lab Assignment Report** cover page (10 marks rubric)
- **Lab Report** cover page (25 marks rubric)
- **Lab Final Report** cover page (40 marks rubric)

## ✨ Features

- **DIU Cover Page Generator** — Fill in your details, preview, and download as PDF
- **PDF Merge** — Upload your assignment PDF and merge it with the cover page
- **Magic Color Scanner** — Convert handwritten assignment photos to PDF (JPG/PNG → A4 PDF)
- **Drag & Drop Page Reorder** — Fix page sequence before downloading
- **Auto-Save** — Remembers your Name, ID, Batch, and Section
- **Mobile Optimized** — Works on phones and tablets
- **High-Resolution Export** — 4× canvas scale for print-quality PDFs

## 🛠️ Tech Stack

- React + Vite
- Tailwind CSS
- html2pdf.js
- pdf-lib
- Lucide React
